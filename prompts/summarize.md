# 内容摘要 Prompt

## 用途
为抓取的内容生成简洁的摘要。

## Prompt 模板

```
请为以下内容生成一个简洁的摘要。

标题: {title}
内容: {content}

要求:
1. 摘要长度: 50-100字
2. 突出核心观点或结论
3. 使用中文，除非原文是纯英文技术术语
4. 不要以"本文"、"这篇文章"开头

只返回摘要内容，不要其他内容。
```

## 输入示例

```
标题: React 18 新特性详解
内容: React 18 引入了并发渲染、自动批处理、Suspense 改进等多项新特性...
```

## 输出示例

```
React 18 带来并发渲染能力，支持可中断渲染和优先级调度。自动批处理减少不必要的重渲染，Suspense 支持服务端渲染，新增 useId、useDeferredValue 等 Hooks。
```

## 使用场景
- RSS 内容入库时
- YouTube 视频入库时
- 手动投喂内容时
