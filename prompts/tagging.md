# 自动标签 Prompt

## 用途
为内容自动生成分类标签。

## Prompt 模板

```
为以下内容生成 3-5 个标签。

标题: {title}
摘要: {summary}

要求:
1. 标签应反映内容的主题领域
2. 优先使用常见的技术/领域术语
3. 使用中文，技术专有名词可用英文
4. 不要使用太宽泛的标签如"技术"、"学习"

返回格式: 用逗号分隔的标签列表
```

## 输入示例

```
标题: 使用 Go 语言实现分布式缓存
摘要: 介绍如何用 Go 实现一个支持一致性哈希的分布式缓存系统
```

## 输出示例

```
Go, 分布式缓存, 一致性哈希, 系统设计, 缓存
```

## 常用标签类别

### 技术领域
- 前端: React, Vue, TypeScript, CSS
- 后端: Go, Python, Java, Node.js
- 基础设施: Kubernetes, Docker, AWS, 运维
- 数据: PostgreSQL, Redis, 数据分析

### 主题类型
- 系统设计, 架构, 性能优化
- 最佳实践, 教程, 案例分析
- 工具, 框架, 库
